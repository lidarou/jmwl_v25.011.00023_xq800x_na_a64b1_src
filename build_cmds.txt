python lunch.py <芯片类型索引号>

3. 查看帮助菜单
python .\make.py -h

4. 配置AP编译选项
python .\make.py ap menuconfig

5. 编译
python .\make.py all  全编译
python .\make.py ap   仅编译ap

6. 清空编译
python .\make.py clean
